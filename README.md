## ⚡ Tech Stack

- **Core:** React 19, Vite 6
- **Styling:** Tailwind CSS 3.4, Custom Editorial Theme
- **Motion & Physics:** Framer Motion 14, Lenis Smooth Scroll 1.3
- **Icons & Assets:** Lucide React, Official Brand SVGs
- **Deployment:** Vercel

---

## 🌟 Key Highlights

- **Cinematic Inertia Scrolling:** Buttery-smooth desktop momentum via Lenis and Framer Motion with native mobile touch preserved.
- **Top Reading Indicator & Back-to-Top:** Hardware-accelerated progress bar and a floating circular SVG scroll ring.
- **Dynamic Aceternity Elements:** Ambient spotlight beams, architectural grid, and an interactive dual-mode portrait.
- **Verified Repositories:** Direct showcase of authentic GitHub repositories and live deployments.
- **Accessible & Responsive:** Full dark/light mode parity and responsive layouts across all screen sizes.
